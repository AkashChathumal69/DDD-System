# Driver Drowsiness Monitor

This Vite application uses MediaPipe Face Landmarker to monitor facial
landmarks, eye aspect ratio (EAR), mouth aspect ratio (MAR), and blink rate
from the webcam.

## Quick Start

1. **Install dependencies**: `pnpm install`
2. **Run the app**: `pnpm dev`
3. **Open browser**: Navigate to the local URL, typically `http://localhost:5173`
